My Services

I provide comprehensive digital solutions tailored to your business needs. I handle every part of your project, from design to deployment.

  • Website Development

    Your website is often the first interaction a client has with your business. I build high-performance, accessible, SEO-ready websites with clean code and custom CMS functionality, giving you full control without breaking the layout.

  • API & Data Integration

    Your software should not live in silos. I build middleware that connects your CRM, accounting software, and third-party services like Stripe, Xero, or Salesforce. I help you eliminate manual data entry and reduce human error.

  • Custom Business Software

    Complex problems require robust solutions. I build secure, scalable web applications using modern frameworks like React, Next.js and TypeScript. I engineer for performance, security, and long-term maintainability.

  • Mobile App Development

    Reach your customers (or staff) directly on their devices. I develop high-performance, cross-platform mobile applications. I deliver native-feeling apps for iOS and Android while reducing development and maintenance costs.

  • UI/UX Design

    Complex functionality fails if users cannot figure out how to use it. I design intuitive interfaces, wireframes, and prototypes that prioritize clarity and efficiency before a single line of code is written.

  • Cloud Hosting & Infrastructure

    Modern software requires modern infrastructure. I manage secure cloud deployments, automated backups, SSL certificates, and server performance. I ensure your applications remain fast, reliable, and protected.

Photographer Portfolio

Frontend · React + TypeScript

An immersive visual portfolio for Ugandan photographer and visual artist Mek Elias, designed to showcase fine-art photography, editorial work and creative direction through cinematic, media-first presentation.

Built with React 18, TypeScript and Vite, the site combines Tailwind CSS and Radix UI with a fullscreen hero slideshow, responsive masonry galleries, an accessible lightbox, category filtering and a validated inquiry form.

EdTech Platform

Frontend · EdTech Platform

An interactive EdTech platform that introduces learners aged 11–16 to artificial intelligence, robotics and data science through gamified course tracks, peer showcases and parent resources.

Built with React, TypeScript and Vite, it includes multi-criteria course discovery, a community feed, a parent and educator resource centre, tiered pricing and a mobile-first interface styled with Tailwind CSS and Radix UI.

MRKT Edge

Frontend · Market Intelligence

Landing page for MRKT Edge, a private market-intelligence terminal. Built with React 19, TanStack Start and strict TypeScript, it presents the product's risk-on/risk-off composite, bias cards, hand-drawn SVG charts and macro calendar with per-route SEO metadata.

MRKT Edge Terminal

Frontend · Market Terminal

The terminal itself: a single dark screen combining a risk-on/risk-off gauge, DXY sparkline, gold bias with confidence, event countdown, expandable asset bias cards, a 13-candle SVG chart, impact-scored headlines, COT positioning and the macro calendar.

People's Hospital

Healthcare Website · Full-Stack

A responsive, server-rendered website for Bwindi Community Hospital in Kanungu, Uganda. It brings services, departments, education, community health, projects, team, news, gallery and contact pages together with a preserved archive of the hospital's published content and Supabase-backed appointment and contact forms.

Loan Management

Built with React, TanStack Start, TypeScript, Zod and Recharts, with typed workflow models, interest and repayment calculations, validated forms and in-memory demo data.
